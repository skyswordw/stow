# Harbor rebrand — handoff

Everything engineering needs to ship the new Harbor look in version 3.0 of the app.
Questions go to #harbor-brand. Mira answers type and colour, Tomas answers motion.

## What's inside

- **Specs** — the brand guidelines (PDF), colour tokens (JSON) and motion notes.
- **Logo** — the mark and the wordmark as SVG, plus a 2x PNG of the mark for places that can't take vector art.
- **Screens** — final comps for Home, Checkout, Onboarding and Settings, light and dark.
- **Photos** — the five approved photos. Keep the crops from page 6 of the guidelines.
- **Fonts** — Atkinson Hyperlegible for the interface, Instrument Serif Italic for headlines. Both use the SIL Open Font License, so they can ship inside the app.
- **Prototype** — a clickable build of the new onboarding. It isn't notarized yet, so macOS asks before opening it.
- **Audio** and **Video** — the two-note sting and the logo reveal for the launch spot.
- **Earlier Rounds** — old explorations, for reference only. Don't use anything from there.

## Rules of thumb

1. Use the tokens, not hex values. `amber.500` is the only accent.
2. Keep the mark at least 24 pt tall. Below that, use the wordmark on its own.
3. Departure times always use tabular figures.
4. Dark mode isn't inverted light mode. See page 5 of the guidelines.

## Changes since round 3

- The beam in the mark is one shape now, so it holds up at small sizes.
- Amber moved from #E8892F to #E2802F. Text on amber buttons is navy, never white, so it passes contrast.
- The checkout button says the price ("Pay $5.50"), never "Submit".
- Onboarding is three screens instead of five.

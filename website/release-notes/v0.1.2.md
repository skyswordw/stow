## Stow 0.1.2

- Pack More Options: per-job helpers, metadata, names, and CPU, plus expanded split presets and custom part sizes (including decimal commas and full-width digits)
- Richer DMG packing: APFS volumes, Applications shortcut, and optional Finder window chrome without mounting
- Optional Keychain vault for archive passwords, with explicit unlock and password-aware previews
- Stream large archive directory listings over XPC instead of blocking on the full tree
- Ship a genuine Harbor sample ZIP for Try the Sample, with integrity checks
- Glance shares Browser navigation and controls, with enclosing-folder context and a Liquid Glass vs classic material preference
- Tray: reveal on drag near the icon or trailing edge, temporary packing groups by default, and clearer drop feedback
- Settings: category map with page-scoped reset scaffolding for Packing and Actions
- Reassemble split ZIP/7Z volumes before opening, and correctly identify split formats in Recents
- Open embedded ZIP archives that have surrounding data
- Accessibility: flatter VoiceOver labels on failures and chrome (partial #93)
- Browser and List reliability: selection, search focus, undo/redo for staged edits, extract of helper files, and Save a Copy staging
- Build and test hardening for Xcode 26.2 / Swift 6.2.3 and non-English Macs
